# Open-source tools for AI-assisted development

I build small local-first tools that make AI coding agent changes easier to inspect, constrain, and verify.

## Projects

| Project | What it does |
| --- | --- |
| [**PatchWitness**](https://github.com/pangxueyuan2-creator/patchwitness) | Trust gate / Change Passport for patches (scope, real tests, impact, offline evidence) |
| [GuardSpec](https://github.com/pangxueyuan2-creator/guardspec) | Compile repo instructions into agent boundaries |
| [RuleRelay](https://github.com/pangxueyuan2-creator/rule-relay) | Explain and validate agent instruction files |
| [TaskToPR](https://github.com/pangxueyuan2-creator/tasktopr) | Turn a GitHub Issue into a tested PR |
| [Repo Privacy Guard](https://github.com/pangxueyuan2-creator/repo-privacy-guard) | Offline secret / privacy scanner |
| [SheetSentry](https://github.com/pangxueyuan2-creator/sheetsentry) | CSV/TSV inspection and safe sanitization |
| [OSS README Studio](https://github.com/pangxueyuan2-creator/oss-readme-studio) | Simple bilingual README generator |

Early stage. Single maintainer.
